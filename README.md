# AI 자료 요약 자동화 도구

여러 개의 텍스트 자료를 한 번에 읽어 Gemini API로 자동 요약하고, 하나의 리포트로 묶어주는 파이썬 도구.
AI를 코드에 연결해 반복 업무를 실제로 없애는 자동화 도구를 직접 제작.

## 문제의식
리서치나 자료 정리를 하다 보면 기사·보고서를 하나하나 열어 읽고 핵심을 추려 정리하는 데 시간이 많이 든다. 자료가 몇 개면 손으로 해도 되지만, 매번 여러 개가 쌓이면 사람이 직접 하는 것보다 자동화하는 게 효율적이다. 그래서 폴더에 자료를 넣기만 하면 요약 리포트가 나오도록 설계하여, 사람은 읽고 판단하는 핵심에만 집중하게 하는 걸 목표로 잡았다.

## 어떻게 작동하나 (AI + 코드 워크플로우)
Python 코드가 폴더의 텍스트 파일을 읽어들이고, 각 자료를 Gemini API에 보내 핵심요약 3줄과 한줄결론 형식으로 요약을 받은 뒤, 결과를 하나의 마크다운 리포트로 합쳐 저장한다. 입력(파일) → AI 호출(API) → 구조화된 출력(리포트)까지 이어지는 하나의 자동화 흐름이다. AI를 챗으로 한 번씩 쓰는 게 아니라, 코드에 붙여 반복 실행하고 확장할 수 있는 형태로 만든 게 핵심이다.

## 주요 기능
- articles 폴더의 모든 .txt 파일을 자동으로 읽음
- 각 자료를 Gemini API로 정해진 형식(핵심요약 3줄 + 한줄결론)으로 요약
- 전체 결과를 summary_report.md 리포트로 자동 저장

## 사용 방법
1. 라이브러리 설치: pip install google-genai
2. Google AI Studio에서 Gemini API 키 발급 (무료)
3. articles 폴더에 요약할 .txt 파일 넣기
4. 실행: python ai_summarizer.py (실행 시 API 키 입력)
5. 생성된 summary_report.md 확인

## 다음 단계
지금은 텍스트 요약에 맞춘 작은 도구지만, 같은 구조로 요약 형식이나 대상(뉴스, 논문, 회의록)을 바꾸거나 매일 자동 실행과 결과 저장을 붙이면 실제 업무용 자동화로 확장할 수 있다.
